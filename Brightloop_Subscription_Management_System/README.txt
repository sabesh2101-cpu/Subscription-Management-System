BRIGHTLOOP SUBSCRIPTION MANAGEMENT SYSTEM
=========================================

A simple front-end demo based on the provided Subscription Management System brief.

HOW TO RUN
1. Extract the ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html in a browser.
   - Recommended: install the "Live Server" extension in VS Code.
   - Right-click index.html and choose "Open with Live Server".

FEATURES
- Dashboard with active subscriptions, payments, outstanding amount and overdue invoices.
- Manage subscriptions, products, customers, invoices, payments and discounts.
- Search records in each section.
- Add records using simple forms.
- Payment entry can mark an invoice as paid when the full invoice amount is recorded.
- Basic report summary and print option.
- Responsive layout for desktop and mobile.
- Records are saved in browser localStorage.

IMPORTANT
- This is a simple front-end prototype for learning and demonstration.
- It does not include a real backend, secure login, email delivery, real payment gateway,
  automatic recurring billing, or multi-user access.
- Data is stored only in the browser where you run it. Clearing browser data may remove it.
- For a real production system, add a backend, database, authentication and payment provider.
